# Vessel for Node.js

Vessel stores binary objects by key in a local directory. The `vessel-storage` package exposes the `Vessel` class to JavaScript and TypeScript on Node.js 24 and later.

- [Node.js user guide](../../Docs/UserGuide/NodeJS/README.md) for setup, a runnable quickstart and common tasks.
- [Node.js API reference](../../Docs/ApiReferences/NodeJS/README.md) for the public contract.
