# Vessel for Python

`vessel-storage` provides a Python API for the Vessel embedded object store. For published versions, use [PyPI](https://pypi.org/project/vessel-storage/) or download the wheel for your platform from [GitHub Releases](https://github.com/noyzone99/Vessel/releases). Published wheels include the native library.

To develop from a checkout, run `python -m pip install ./Bindings/python` and supply a matching native build using `library_path` or `VESSEL_LIBRARY_PATH`.
