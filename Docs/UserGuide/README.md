# User guide

| Language | How to use Vessel | Guide |
| --- | --- | --- |
| C# | Managed `Vessel.Core` library on .NET 8 or .NET 10 | [C#](CSharp/README.md) |
| C | NativeAOT shared library and C header | [C](C/README.md) |
